单文件静态页完成输入需求、三人评审、测试设计稿、HTML 测试设计文档和 Excel 测试用例导出。 页面直接调用可配置的 OpenAI 兼容 LLM 接口，不再依赖 Python 后端流程。

可行性结论

  • 当前核心能力本质上是 prompt 编排、结构化 JSON 校验、文档拼装和 Excel 导出，这些都可以在浏览器端完成。
  • 新的静态页保留现有测试环境约束规则：优先已勾选环境，必须依赖未勾选环境时仍保留设计并输出风险。
  • 三轮评审里的待确认问题、用户确认答案和确认历史会保存在浏览器本地，并进入设计文档和 Excel。
  • 页面假设你配置的 LLM 接口支持浏览器跨域访问，以及 OpenAI 兼容的 `chat/completions` 协议；本地 Ollama 可直接兼容。

LLM 配置

页面直接请求浏览器可访问的 OpenAI 兼容接口；配置会保存在本地浏览器。

默认拼接为 `<baseUrl>/chat/completions`；若填写本地 Ollama `http://127.0.0.1:11434`，会自动走 `/v1/chat/completions`。

仅保存在当前浏览器 localStorage；请避免在不可信设备中使用。本地 Ollama / 无鉴权网关可留空。

按你的供应商模型名填写；例如 Ollama 可填 `qwen2.5:14b`、`llama3.1:8b`。

适用前提：目标接口允许浏览器 CORS 调用；如果你直接双击打开 HTML，也要确保供应商接口允许来自 `file://` 或无来源页面的请求。
